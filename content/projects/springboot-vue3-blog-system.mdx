## 项目简介

这是一个基于 **Spring Boot 3 + Vue 3** 前后端分离架构的个人博客系统，提供了完整的博客功能——从用户注册登录、文章发布与管理，到分类管理、评论互动、内容审核，同时支持管理员对平台内容进行审核与统计分析。

> 在线体验：[首页 - 个人博客](https://blog.cloudyue.com.cn/)

## 核心功能

### 用户系统

- 注册、登录与个人资料管理
- 基于 JWT 的无状态 Token 认证
- Spring Security 角色权限控制（普通用户 / 管理员）

### 文章管理

- Markdown 编辑器，支持代码高亮
- 分类与标签体系
- 文章审核流程（待审核 → 通过 / 驳回 / 下架）
- 置顶功能与多维度排序（最新、最热、浏览量）

### 评论系统

- 多级嵌套回复，树形结构展示
- 评论点赞与举报机制
- 管理员可处理举报（驳回或删除违规评论）

### 管理后台

- 内容审核：文章与评论的审核管理
- 数据统计：用户数、文章数、评论数一览
- 用户管理：角色分配与账号管理

### 文件上传

- 头像、封面图上传
- 图片预览支持

## 项目亮点

### 统一响应格式

所有 API 返回统一的 `Result<T>` 结构，前端可统一拦截处理：

```java
@Data
public class Result<T> {
    private Integer code;
    private String message;
    private T data;

    public static <T> Result<T> success(T data) { ... }
    public static <T> Result<T> error(String message) { ... }
}
```

### 全局异常处理

通过 `@RestControllerAdvice` 统一捕获异常，包括参数校验异常和运行时异常，保证接口返回格式一致。

### 自动填充与逻辑删除

- MyBatis-Plus `MetaObjectHandler` 自动填充 `createTime` / `updateTime`
- 全局逻辑删除配置，`deleted` 字段标记删除状态

### 安全认证

JWT Filter 拦截请求，Spring Security 配置无状态会话，公开接口（注册、登录、文章浏览）无需认证，写操作需登录。

## 数据库设计

### 核心表

- **user** — 用户表：用户名、密码、昵称、头像、角色等
- **article** — 文章表：标题、摘要、内容、封面、标签、浏览量、点赞数、审核状态等
- **comment** — 评论表：支持 `parentId` 实现多级嵌套
- **category** — 分类表

### 设计要点

- 所有表包含 `create_time`、`update_time`、`deleted` 字段
- 合理建立索引（`user_id`、`category_id`、`create_time`）
- 使用 `utf8mb4` 字符集支持 emoji 等特殊字符

## 部署方式

### 环境要求

- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Maven 3.8+

### 后端

```bash
# 配置数据库连接后启动
mvn spring-boot:run
```

### 前端

```bash
npm install
npm run dev      # 开发模式
npm run build    # 生产构建
```

### 生产部署（Nginx 反向代理）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        root /path/to/dist;
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
