## 项目简介

植多多是一个全栈式植物百科平台，整合了 AI 智能识别、植物数据可视化和微信小程序，为用户提供从识别到查询、从学习到养护的一站式植物知识服务。

> 在线体验：[植多多](http://101.34.218.178/)

## 核心功能

### 智能植物识别

- **双引擎识别**：集成 Plant.id 和百度植物识别两大 AI 平台，提供高精度植物识别服务
- **多模式支持**：支持图片上传识别和实时拍照识别两种方式
- **微信小程序**：移动端扫码识别，实现"随拍随查"的便捷体验

### 植物信息查询

- **全面数据库**：包含丰富的植物种类信息，涵盖名称、分类、特征、分布等详细数据
- **智能搜索**：支持按名称、分类、特征等多维度关键字搜索
- **详情展示**：提供图文并茂的植物详情页面，包含 3D 模型展示

### AI 智能问答

- **深度集成**：接入 DeepSeek AI 大模型，提供专业的植物知识问答
- **养护建议**：基于植物特性提供个性化的养护指导
- **自然交互**：支持自然语言对话，提升用户体验

### 数据可视化

- **热力图展示**：基于 Leaflet 的植物地理分布热力图
- **统计图表**：使用 Chart.js 展示植物分类、分布等统计数据
- **交互式地图**：支持缩放、筛选等交互操作

## 技术架构

### 前端技术栈

| 技术 | 用途 |
| :--- | :--- |
| Vue 3 + Composition API | 前端框架 |
| Vite (Rolldown) | 构建工具 |
| Vue Router | 单页应用路由 |
| Axios | HTTP 请求 |
| Leaflet | 地图与热力图 |
| Chart.js | 统计图表 |
| Three.js | 3D 模型展示 |
| PWA Service Worker | 离线支持 |

### 后端技术栈

| 技术 | 用途 |
| :--- | :--- |
| Node.js 18+ / Express 5 | 服务端运行环境 |
| MySQL 8.0+ (mysql2) | 数据库 |
| PM2 | 生产环境进程管理 |
| Plant.id API | AI 植物识别 |
| 百度植物识别 API | AI 植物识别（国内） |
| DeepSeek API | AI 智能问答 |

### 微信小程序

- 微信小程序原生开发
- 自定义请求工具类封装
- 首页、搜索、详情、扫码识别等核心页面

```

│   ├── app.js               # Express 应用入口

│   └── config/              # 配置文件目录
```
