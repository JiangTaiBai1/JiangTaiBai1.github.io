# SpringBoot 3.0 + Vue3 个人博客系统开发实战

在当今数字化时代，拥有一个属于自己的博客系统不仅是展示技术能力的窗口，更是记录学习心得、分享经验的重要平台。本文将详细介绍如何使用最新的技术栈 **SpringBoot 3.0 + Vue3** 从零开始构建一个功能完善、架构清晰的个人博客系统。

> 🎉 **在线演示**：[首页 - 个人博客](https://blog.cloudyue.com.cn/)

## 项目概述

本项目是一个基于 **Spring Boot 3 + Vue 3** 前后端分离架构的个人博客系统。系统提供了完整的博客功能，包括用户注册登录、文章发布与管理、分类管理、评论互动、内容审核等，同时支持管理员对平台内容进行审核与统计分析。

### 核心功能

- **用户系统**：注册、登录、个人资料管理、角色权限控制
- **文章管理**：Markdown编辑、分类标签、审核流程、置顶功能
- **评论系统**：多级嵌套回复、评论点赞、评论举报
- **管理后台**：内容审核、数据统计、用户管理
- **文件上传**：头像、封面图上传，支持图片预览

### 用户认证与授权

#### JWT Token认证流程

```java
// JWT工具类核心代码
@Component
public class JwtUtil {
    @Value("${jwt.secret}")
    private String secret;
    
    @Value("${jwt.expiration}")
    private Long expiration;
    
    // 生成Token
    public String generateToken(String username, Long userId) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("username", username);
        
        return Jwts.builder()
                .claims(claims)
                .subject(username)
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + expiration))
                .signWith(getSecretKey())
                .compact();
    }
    
    // 验证Token
    public boolean validateToken(String token) {
        return !isTokenExpired(token) && getUsernameFromToken(token) != null;
    }
}
```

#### Spring Security配置

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(AbstractHttpConfigurer::disable)
            .cors(cors -> cors.configurationSource(corsConfigurationSource()))
            .sessionManagement(session -> 
                session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/auth/**").permitAll()
                .requestMatchers(HttpMethod.GET, "/article/**").permitAll()
                .anyRequest().authenticated()
            )
            .addFilterBefore(jwtAuthenticationFilter, 
                UsernamePasswordAuthenticationFilter.class);
        
        return http.build();
    }
}
```

### 文章管理模块

#### 文章分页查询

```java
@Service
public class ArticleServiceImpl extends ServiceImpl<ArticleMapper, Article> 
    implements ArticleService {
    
    @Override
    public Page<Article> getArticlePage(Integer current, Integer size, 
                                        Long categoryId, String keyword, 
                                        Long userId, Integer published, 
                                        Integer auditStatus, String orderBy) {
        Page<Article> page = new Page<>(current, size);
        LambdaQueryWrapper<Article> wrapper = new LambdaQueryWrapper<>();
        
        // 多条件筛选
        if (userId != null) {
            wrapper.eq(Article::getUserId, userId);
        }
        if (categoryId != null) {
            wrapper.eq(Article::getCategoryId, categoryId);
        }
        if (StringUtils.hasText(keyword)) {
            wrapper.and(w -> w
                .like(Article::getTitle, keyword)
                .or()
                .like(Article::getSummary, keyword)
            );
        }
        
        // 排序处理
        if ("hot".equals(orderBy)) {
            wrapper.orderByDesc(Article::getViews, Article::getLikes);
        } else if ("views".equals(orderBy)) {
            wrapper.orderByDesc(Article::getViews);
        } else {
            wrapper.orderByDesc(Article::getCreateTime);
        }
        
        return page(page, wrapper);
    }
}
```

public enum AuditStatus {
    PENDING(0, "待审核"),
    APPROVED(1, "审核通过"),
    REJECTED(2, "审核驳回"),
    OFFLINE(3, "已下架");
    
    private final int code;
    private final String desc;
}

// 审核接口
@PreAuthorize("hasRole('ADMIN')")
@PutMapping("/audit/{id}")
public Result<?> auditArticle(@PathVariable Long id, 
                              @RequestBody AuditRequest request) {
    Article article = articleService.getById(id);
    article.setAuditStatus(request.getStatus());
    article.setAuditReason(request.getReason());
    article.setAuditTime(LocalDateTime.now());
    article.setAuditUserId(getCurrentUserId());
    articleService.updateById(article);
    return Result.success("审核完成");
}

### 全局异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidationException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getAllErrors().stream()
            .map(DefaultMessageSourceResolvable::getDefaultMessage)
            .collect(Collectors.joining(", "));
        return Result.error(message);
    }
    
    @ExceptionHandler(RuntimeException.class)
    public Result<?> handleRuntimeException(RuntimeException e) {
        return Result.error(e.getMessage());
    }
}
```

## 常见问题解答

### 如何修改数据库配置？

在 `backend/src/main/resources/application.yml` 中修改以下配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/your_database?useUnicode=true&characterEncoding=utf-8&useSSL=false
    username: your_username
    password: your_password
```

### 如何配置JWT密钥？

在 `application.yml` 中修改JWT配置：

```yaml
jwt:
  secret: your-secret-key-here
  expiration: 604800000  # 7天，单位毫秒
```
